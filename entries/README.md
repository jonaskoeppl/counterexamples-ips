# Entries

One folder per question, numbered in order of creation:

```
NNNN-short-slug/
├── question.md     # the claim being tested
├── raw/            # verbatim AI outputs: YYYY-MM-DD_model-name.md
├── digest.md       # verified, human-readable counterexample
├── followups.md    # questions raised by this entry
└── code/           # optional: simulations, figures
```

To start a new entry, copy `templates/` to `entries/NNNN-short-slug/` and fill in the files.
